ПАМЯТКА СЕМЬИ POLIX CREATOR - KATO
Оверлей-каталог статей Majestic RP.

УСТАНОВКА
1. Скачайте установщик PolixCreatorKATO-Setup-x.x.x.exe из раздела Releases репозитория.
2. Запустите и установите. Windows может показать предупреждение (программа без подписи):
   «Подробнее» → «Выполнить в любом случае».

ОБНОВЛЕНИЕ БЕЗ ПЕРЕУСТАНОВКИ
- Программа сама проверяет обновления при запуске и каждые 3 часа.
- Когда новая версия скачана, появится окно «Перезапустить сейчас / Позже».
- Вручную: правый клик по иконке в трее → «Проверить обновления».

ГОРЯЧИЕ КЛАВИШИ
- Alt+Q — показать / скрыть оверлей.

ТРЕЙ
- Иконка в скрытых значках. Клик — показать/скрыть, правый клик — меню.
- «Выйти полностью» закрывает программу.

ВЫПУСК НОВОЙ ВЕРСИИ (для автора)
1. В package.json поднимите "version" (например 1.0.1).
2. Закоммитьте и создайте тег:
     git tag v1.0.1
     git push origin v1.0.1
3. GitHub Actions соберёт установщик и выложит его в Releases.
   Установленные программы сами увидят новую версию.
