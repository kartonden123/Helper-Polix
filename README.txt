POLIX HELPER - BY KATO
Оверлей-справочник по статьям, кодексам и уставам Majestic RP.

УСТАНОВКА
1. Скачайте PolixHelper-Setup-x.x.x.exe из раздела Releases репозитория.
2. Запустите. Windows может показать предупреждение (программа без подписи):
   "Подробнее" -> "Выполнить в любом случае".

ГОРЯЧИЕ КЛАВИШИ
- Alt+Q (запасная: Ctrl+Alt+Q) - показать / скрыть меню.
- Esc - назад, на пустом поиске - скрыть.

АВТООБНОВЛЕНИЕ
- Программа сама проверяет обновления при запуске и каждые 3 часа.
- Когда новая версия скачана, появится окно "Перезапустить сейчас / Позже".
- Вручную: правый клик по значку в трее -> "Проверить обновления".

ВЫПУСК НОВОЙ ВЕРСИИ (для автора)
1. В package.json поднимите "version" (например 1.2.1).
2. Закоммитьте и создайте тег:
     git tag v1.2.1
     git push origin v1.2.1
3. GitHub Actions соберёт установщик и выложит его в Releases.
