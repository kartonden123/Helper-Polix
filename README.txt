СБОРКА PORTABLE .EXE (Windows)

1. Установите Node.js LTS с https://nodejs.org
2. Распакуйте папку overlay в любое место
3. В папке откройте терминал и выполните:
     npm install
     npm run build
4. Готовый файл: dist\PolixCreatorKATO-1.0.0.exe
   Он запускается без установки, можно класть на флешку.

ЗАПУСК БЕЗ СБОРКИ (для проверки):
     npm install
     npm start

ГОРЯЧИЕ КЛАВИШИ
- Alt+Q — показать / скрыть оверлей
- Перетаскивание за верхнюю панель поиска

НАСТРОЙКИ (main.js, верх файла)
- OPACITY — прозрачность (0.9 = почти непрозрачно, 0.6 = сильно прозрачно)
- WIDTH — ширина в пикселях
- HEIGHT_RATIO — высота в долях экрана (0.82 = 82%)
- SIDE — 'right' (справа, во всю высоту) или 'top' (полоса сверху, как на скрине /promo)

ВАЖНО ДЛЯ GTA
Оверлей поверх игры видно только если GTA работает в режиме
«Оконный без рамки» (Настройки → Графика → Тип экрана).
В полноэкранном режиме окно будет под игрой.

СБОРКА НА GITHUB
1. Залейте папку overlay в репозиторий (с файлом .github/workflows/build.yml).
2. Откройте вкладку Actions → Build portable exe → Run workflow
   (или просто сделайте push в main/master).
3. Когда сборка зелёная, скачайте артефакт PolixCreatorKATO-portable (внутри .exe).
