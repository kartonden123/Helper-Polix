# Polix Helper

**Семейный помощник для Majestic RP.** Быстрый поиск по статьям УК и ДК, кодексам и уставам прямо поверх игры. Нажали горячую клавишу, ввели номер статьи или слово, получили розыск, срок, залог и штраф.

> By **KATO** · для семьи Polix

## Зачем он нужен

Во время игры некогда листать форум и искать нужную статью. Polix Helper держит всё под рукой: компактное меню появляется поверх игры, показывает результат за секунду и так же быстро прячется.

## Что умеет

- **Поиск по статьям.** Вводите номер (`6.2`, `12.8`) или слово (`оружие`, `убийство`). Поиск понимает окончания слов.
- **Карточка статьи.** Розыск в звёздах, срок в месяцах, залог, штраф, пометка о судимости и полный текст.
- **Поиск по кодексам и уставам.** Находит фрагменты в УК, ДК, процессуальном, административном, трудовом кодексах, уставах LSPD, Sheriff, FIB, SANG и законе о прокуратуре.
- **Неприкосновенные лица.** Кто неприкосновенен и по каким статьям его всё же можно задержать.
- **Памятка.** Общие правила задержания и работы.
- **Фильтр УК / ДК** и быстрый список статей с судимостью (розыск 4–5).
- **Управление с клавиатуры.** Стрелки выбирают, Enter открывает, Esc возвращает назад.
- **Не мешает игре.** Прозрачные места окна пропускают клики, а окно прячется одной клавишей.
- **Само обновляется.** Новые версии скачиваются автоматически.

## Установка

1. Откройте раздел [Releases](../../releases/latest).
2. Скачайте `PolixHelper-Setup-x.x.x.exe` и запустите.
3. Windows может показать предупреждение, потому что программа не подписана. Нажмите **«Подробнее» → «Выполнить в любом случае»**.
4. При первом запуске войдите через Discord (см. ниже).

## Горячие клавиши

| Клавиши | Действие |
| --- | --- |
| `Alt + Q` | показать или скрыть меню |
| `Ctrl + Alt + Q` | то же самое, запасной вариант |
| `Esc` | назад, а на пустом поиске скрыть меню |
| `↑` `↓` / `Enter` | выбрать результат / открыть статью |

Значок в трее: клик показывает или скрывает меню, правый клик открывает дополнительные действия.

## Вход через Discord

Хелпер предназначен для семьи, поэтому при первом запуске нужно войти через Discord. Программа только проверяет, что вы состоите на сервере семьи. Пароль от Discord она не видит и не хранит.

Если вас убрали с сервера, хелпер перестанет открываться после ближайшей проверки. Она выполняется раз в несколько часов.

## Обновления

Программа сама проверяет новые версии при запуске и каждые 3 часа. Когда обновление скачано, появится окно «Перезапустить сейчас / Позже». Проверить вручную: правый клик по значку в трее → «Проверить обновления».

История изменений находится в разделе [Releases](../../releases).

## Предложения и ошибки

Нашли ошибку или хотите улучшение? Напишите в канал «предложение-для-улучшение-хелпера» на сервере семьи или создайте [Issue](../../issues) в этом репозитории.

## Важно

- Данные взяты с форума Majestic RP и могут устареть. Если на сервере что-то изменилось, ориентируйтесь на форум.
- Проект неофициальный и никак не связан с Majestic RP.
- Для работы поверх игры включите в GTA режим окна без рамки. В полноэкранном режиме меню может не отображаться.
